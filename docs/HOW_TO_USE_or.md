## 📐 ୧୧ଟି କାଲକୁଲେଟର ସମ୍ପୂର୍ଣ୍ଣ ଗାଇଡ୍ / 11 कैलकुलेटर गाइड

### 🔹 କଂକ୍ରିଟ୍ ଏବଂ 50 କେଜି ସିମେଣ୍ଟ ବସ୍ତା (IS 456)
- **ବିବରଣୀ / विवरण / Details**: ଛାତ ଢଳାଇ, ବିମ୍, କଲମ୍ ପାଇଁ ସିମେଣ୍ଟ ବସ୍ତା, ବାଲି ଏବଂ ଗୋଡ଼ି (ବ୍ରାସ) ହିସାବ।

### 🔹 ଡ୍ରାଇୱାଲ୍ ଏବଂ ପ୍ଲାଷ୍ଟର
- **ବିବରଣୀ / विवरण / Details**: ଜିପସମ୍ ବୋର୍ଡ ଏବଂ ୧୨ମିମି / ୨୦ମିମି କାନ୍ଥ ପ୍ଲାଷ୍ଟର ସାମଗ୍ରୀ।

### 🔹 ଭିଟ୍ରିଫାଇଡ୍ ଚଟାଣ ଏବଂ କାନ୍ଥ ଟାଇଲ୍ସ
- **ବିବରଣୀ / विवरण / Details**: ୬୦୦x୬୦୦ ଏବଂ ୬୦୦x୧୨୦୦ ଟାଇଲ୍ ବାକ୍ସ, ସ୍କର୍ଟିଂ ଏବଂ ଅଠା।

### 🔹 ଇଟା ଗାନ୍ଥୁଣୀ ଏବଂ TMT ରଡ୍ (IS 1786)
- **ବିବରଣୀ / विवरण / Details**: ଲାଲ ଇଟା, AAC ବ୍ଲକ୍ ଏବଂ Fe 500D TMT ରଡ୍ ଓଜନ (କିଲୋ / ଟନ୍)।

### 🔹 ରଙ୍ଗ ଏବଂ ୱାଲ୍ ପୁଟି
- **ବିବରଣୀ / विवरण / Details**: କାନ୍ଥ ଓ ଛାତ ରଙ୍ଗ (ଲିଟର), ୪୦ କେଜି ପୁଟି ବସ୍ତା ଏବଂ ପ୍ରାଇମର୍।

### 🔹 ଛାତ ଢଳାଇ ଏବଂ ୱାଟରପ୍ରୁଫିଂ
- **ବିବରଣୀ / विवरण / Details**: RCC ଛାତ ଢଳାଇ, ୱାଟରପ୍ରୁଫିଂ କେମିକାଲ୍ ଏବଂ ରୁଫିଂ ଶିଟ୍।

### 🔹 ଭଡ଼ା ଆୟ ଏବଂ କ୍ୟାପ୍ ରେଟ୍
- **ବିବରଣୀ / विवरण / Details**: ବାର୍ଷିକ ନିଟ୍ ଭଡ଼ା ଆୟ (NOI) ଏବଂ ମ୍ୟୁନିସିପାଲିଟି ଟ୍ୟାକ୍ସ।

### 🔹 ଗୃହ ଋଣ EMI ଏବଂ ଟ୍ୟାକ୍ସ ରିହାତି
- **ବିବରଣୀ / विवरण / Details**: ମାସିକ କିସ୍ତି, ଧାରା 24b (₹୨ ଲକ୍ଷ ଛାଡ଼) ଏବଂ 80C ଟ୍ୟାକ୍ସ ସଞ୍ଚୟ।

### 🔹 ସମ୍ପତ୍ତି ପୁନର୍ବିକ୍ରୟ ଏବଂ ୧୨.୫% LTCG ଟ୍ୟାକ୍ସ
- **ବିବରଣୀ / विवरण / Details**: ବଜେଟ୍ ୨୦୨୪ ର ୧୨.୫% ପୁଞ୍ଜି ଲାଭ ଟ୍ୟାକ୍ସ ଏବଂ ଲାଭ।

### 🔹 ନିର୍ମାଣ ଋଣ ସୁବିଧା
- **ବିବରଣୀ / विवरण / Details**: ନିର୍ମାଣ ଋଣ, ସୁଧ ହିସାବ ଏବଂ ପ୍ରୋସେସିଂ ଫି।

### 🔹 HVAC ଏସି ଟନେଜ୍ ଏବଂ ବିଜୁଳି ବିଲ୍

## 📱 ୧୦୦% ଅଫଲାଇନ୍ PWA ସୁବିଧା (Offline Usage on Site)
1. **Android (Chrome)**: ମେନୁ (3 dots) ଖୋଲନ୍ତୁ $\rightarrow$ **"Install App"** କିମ୍ବା **"Add to Home Screen"** ଚୟନ କରନ୍ତୁ।
2. **iPhone / iPad (Safari)**: **Share** ବଟନ୍ ଦବାନ୍ତୁ $\rightarrow$ **"Add to Home Screen"** ବାଛନ୍ତୁ।
3. **Computer (Chrome/Edge)**: ଆଡ୍ରେସ୍ ବାରରେ ଥିବା **Install** ଆଇକନ୍ କ୍ଲିକ୍ କରନ୍ତୁ।
