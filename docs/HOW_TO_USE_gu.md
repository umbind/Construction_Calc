## 🌟 ମୁଖ୍ୟ ବୈଶିଷ୍ଟ୍ୟ / मुख्य विशेषताएं (Key Features)

#### 🚀 ૧. એક ક્લિકમાં કેલ્ક્યુલેટર બદલો
ટોચના ક્વિક સ્વિચરથી સરળતાથી ટૂલ બદલો.

#### 🚀 ૨. ભારતીય પ્રીસેટ્સ
સ્ટાન્ડર્ડ માપ આપમેળે ભરવા પ્રીસેટ પર ક્લિક કરો.

#### 🚀 ૩. ૧૧ ભારતીય પ્રાદેશિક ભાષાઓ
🌐 ભાષા બટન પર ક્લિક કરીને ભાષા પસંદ કરો.

#### 🚀 ૪. કોપી અને CSV એક્સપોર્ટ
વોટ્સએપ માટે કોપી કરો અથવા એક્સેલ CSV ડાઉનલોડ કરો.

#### 🚀 ૫. ૧૦૦% ઓફલાઇન PWA
ઇન્ટરનેટ વિના પણ કન્સ્ટ્રક્શન સાઇટ પર વાપરો.

## 📐 ୧୧ଟି କାଲକୁଲେଟର ସମ୍ପୂର୍ଣ୍ଣ ଗାଇଡ୍ / 11 कैलकुलेटर गाइड

### 🔹 કોંક્રિટ અને 50kg સિમેન્ટ થેલીઓ (IS 456)
- **ବିବରଣୀ / विवरण / Details**: ધાબા, બીમ, કોલમ માટે સિમેન્ટ, રેતી અને કપચી (બ્રાસ) ની ગણતરી.

### 🔹 ડ્રાયવોલ અને સિમેન્ટ પ્લાસ્ટર
- **ବିବରଣୀ / विवरण / Details**: જીપ્સમ શીટ્સ અને ૧૨mm/૨૦mm દિવાલ પ્લાસ્ટર.

### 🔹 વિટ્રિફાઇડ ફ્લોર અને વોલ ટાઇલ્સ
- **ବିବରଣୀ / विवरण / Details**: ૬૦૦x૬૦૦ અને ૬૦૦x૧૨૦૦ ટાઇલ્સ બોક્સ, સ્કીર્ટીંગ અને એડહેસિવ.

### 🔹 ચણતર અને TMT સ્ટીલ (IS 1786)
- **ବିବରଣୀ / विवरण / Details**: લાલ ઈંટો, AAC બ્લોક્સ અને Fe 500D TMT સળિયાનું વજન (કિલો / ટન).

### 🔹 કલર અને વોલ પુટ્ટી
- **ବିବରଣୀ / विवरण / Details**: કલર (લીટર), ૪૦ કિલો પુટ્ટી બેગ અને પ્રાઈમર.

### 🔹 ધાબુ અને વોટરપ્રૂફિંગ
- **ବିବରଣୀ / विवरण / Details**: RCC ધાબુ, વોટરપ્રૂફિંગ કેમિકલ અને રૂફિંગ શીટ્સ.

### 🔹 ભાડાની આવક અને કેપ રેટ
- **ବିବରଣୀ / विवरण / Details**: ચોખ્ખી વાર્ષિક ભાડાની આવક (NOI) અને ટેક્સ કપાત.

### 🔹 હોમ લોન EMI અને ટેક્સ બચત
- **ବିବରଣୀ / विवरण / Details**: માસિક EMI, કલમ 24b (₹2 લાખ છૂટ) અને 80C ટેક્સ બચત.

### 🔹 પ્રોપર્ટી રિસેલ અને ૧૨.૫% LTCG ટેક્સ
- **ବିବରଣୀ / विवरण / Details**: બજેટ ૨૦૨૪ નો ૧૨.૫% કેપિટલ ગેઇન્સ ટેક્સ.

### 🔹 કન્સ્ટ્રક્શન લોન ફેસિલિટી
- **ବିବରଣୀ / विवरण / Details**: સ્ટેજ મુજબ ક્રેડિટ, વ્યાજ અને પ્રોસેસિંગ ફી.

### 🔹 HVAC એસી ટનેજ અને લાઇટ બિલ
- **ବିବରଣୀ / विवरण / Details**: NBC 2016 વાતાવરણ ઝોન અને અંદાજિત માસિક વીજળી બિલ.
