## 📐 ୧୧ଟି କାଲକୁଲେଟର ସମ୍ପୂର୍ଣ୍ଣ ଗାଇଡ୍ / 11 कैलकुलेटर गाइड

### 🔹 ਕੰਕਰੀਟ ਅਤੇ 50kg ਸੀਮਿੰਟ ਬੈਗ (IS 456)
- **ବିବରଣୀ / विवरण / Details**: ਛੱਤ ਦੀ ਢਲਾਈ, ਬੀਮ ਅਤੇ ਪਿੱਲਰਾਂ ਲਈ ਸੀਮਿੰਟ, ਰੇਤਾ ਅਤੇ ਬਜਰੀ (ਬਰਾਸ) ਦੀ ਗਿਣਤੀ।

### 🔹 ਡਰਾਈਵਾਲ ਅਤੇ ਪਲਾਸਟਰ
- **ବିବରଣୀ / विवरण / Details**: ਜਿਪਸਮ ਸ਼ੀਟਾਂ ਅਤੇ 12mm / 20mm ਸੀਮਿੰਟ ਪਲਾਸਟਰ।

### 🔹 ਵਿਟਰੀਫਾਈਡ ਫਲੋਰ ਅਤੇ ਕੰਧ ਟਾਈਲਾਂ
- **ବିବରଣୀ / विवरण / Details**: 600x600 ਅਤੇ 600x1200 ਟਾਈਲਾਂ ਦੇ ਡੱਬੇ, ਸਕਾਰਟਿੰਗ ਅਤੇ ਕੈਮੀਕਲ।

### 🔹 ਇੱਟਾਂ ਦੀ ਚਿਣਾਈ ਅਤੇ TMT ਸਰੀਆ (IS 1786)
- **ବିବରଣୀ / विवरण / Details**: ਲਾਲ ਇੱਟਾਂ, AAC ਬਲਾਕ ਅਤੇ Fe 500D TMT ਸਰੀਏ ਦਾ ਭਾਰ (ਕਿਲੋ / ਟਨ)।

### 🔹 ਪੇਂਟ ਅਤੇ ਕੰਧ ਪੁੱਟੀ
- **ବିବରଣୀ / विवरण / Details**: ਕੰਧਾਂ ਅਤੇ ਛੱਤ ਦਾ ਰੰਗ (ਲੀਟਰ), 40kg ਪੁੱਟੀ ਦੇ ਥੈਲੇ ਅਤੇ ਪ੍ਰਾਈਮਰ।

### 🔹 ਛੱਤ ਦੀ ਢਲਾਈ ਅਤੇ ਵਾਟਰਪਰੂਫਿੰਗ
- **ବିବରଣୀ / विवरण / Details**: RCC ਛੱਤ, ਵਾਟਰਪਰੂਫਿੰਗ ਕੈਮੀਕਲ ਅਤੇ ਟੀਨ ਦੀਆਂ ਸ਼ੀਟਾਂ।

### 🔹 ਕਿਰਾਇਆ ਆਮਦਨ ਅਤੇ ਕੈਪ ਰੇਟ
- **ବିବରଣୀ / विवरण / Details**: ਸਾਲਾਨਾ ਸ਼ੁੱਧ ਕਿਰਾਇਆ (NOI) ਅਤੇ ਮਿਊਂਸਪਲ ਟੈਕਸ।

### 🔹 ਹੋਮ ਲੋਨ EMI ਅਤੇ ਟੈਕਸ ਬਚਤ
- **ବିବରଣୀ / विवरण / Details**: ਮਹੀਨਾਵਾਰ ਕਿਸ਼ਤ, ਧਾਰਾ 24b (₹2 ਲੱਖ ਛੋਟ) ਅਤੇ 80C ਟੈਕਸ ਬਚਤ।

### 🔹 ਪ੍ਰਾਪਰਟੀ ਰੀਸੇਲ ਅਤੇ 12.5% LTCG ਟੈਕਸ
- **ବିବରଣୀ / विवरण / Details**: ਬਜਟ 2024 ਦਾ 12.5% ਕੈਪੀਟਲ ਗੇਨ ਟੈਕਸ ਅਤੇ ਮੁਨਾਫਾ।

### 🔹 ਉਸਾਰੀ ਕਰਜ਼ਾ ਸਹੂਲਤ
- **ବିବରଣୀ / विवरण / Details**: ਕੰਸਟ੍ਰਕਸ਼ਨ ਲੋਨ, ਵਿਆਜ ਅਤੇ ਪ੍ਰੋਸੈਸਿੰਗ ਫੀਸ।

### 🔹 HVAC ਏਸੀ ਟਨੇਜ ਅਤੇ ਬਿਜਲੀ ਬਿੱਲ
- **ବିବରଣୀ / विवरण / Details**: NBC 2016 ਜਲਵਾਯੂ ਜ਼ੋਨ ਅਤੇ ਅੰਦਾਜ਼ਨ ਮਹੀਨਾਵਾਰ ਬਿਜਲੀ ਬਿੱਲ।
